# Simsong Presenter 2

[Simsong Presenter 2](https://nobschulth.github.io/simsong-presenter-2/)

This is a website to present songs from [Songselect](https://songselect.ccli.com) in a quick and easy way.

## Usage

Go to <https://nobschulth.github.io/simsong-presenter-2/> and click "New" to create a new songbook. Now you can go to <https://songselect.ccli.com> and copy a songtext to your clipboard. If you press the paste symbol, you can create a new song by pasting the text you copied. To download the songbook as json, click "Download". Click a song title to start presenting a song.

## Changes from Simsong Presenter 1

This is a complete rewrite in typescript with react. The first version was written in C. This new version has features like localization support, saving the songbook in local storage and improved UI/UX.
